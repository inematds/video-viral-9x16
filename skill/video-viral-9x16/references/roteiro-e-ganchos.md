# Roteiro, ganchos e mapa de cenas

## 1. Estrutura que funcionou (40 a 50 s)

| Bloco | Tempo | Função | O que vai na tela |
|---|---|---|---|
| **Gancho** | 0 a 3 s | Interromper o scroll | Palavra gigante tremendo, borda vermelha pulsando, record scratch, close de rosto chocado ou mão em "PARE" |
| **Promessa** | 3 a 6 s | Benefício nº 1 + 1ª virada da trilha | Carimbo ("DE GRAÇA") + selo "R$0" + sub-drop |
| **O que é** | 6 a 11 s | Categoria + analogia | "SISTEMA DE AGENTES" → "SEU PRÓPRIO JARVIS" (HUD) |
| **Como funciona** | 11 a 23 s | 3 ou 4 recursos concretos com números | Contador 10→100→1.000, pipeline animado, chips de integrações |
| **Prova** | 23 a 31 s | Mostrar funcionando + o que vem junto | Notificações do Telegram chegando; card do curso |
| **Contraste** | 31 a 35 s | Antes x depois | "MODO MANUAL" riscado → "ESCALA COM AGENTES" |
| **Repetição** | 35 a 38 s | Repetir o benefício + 2ª virada (a maior) | Carimbo "GRÁTIS!" + confete |
| **Autoridade** | 38 a 43 s | Por que confiar | Globo + "MAIOR PLATAFORMA… DO BRASIL" + PT/ES/EN |
| **CTA** | 43 s até o fim | Uma ação só | Cartão final: "CORRE!" + domínio + botão com toque animado |

Regras do roteiro:
- **2,4 a 2,6 palavras por segundo** com voz animada. 45 s dá cerca de 110 palavras.
- Frases de 3 a 8 palavras. Uma ideia por frase. Cada frase vira um "beat" visual.
- Fale a palavra-chave **no fim da frase** ("Ele é de **graça**."). É nela que entram o carimbo e a virada.
- Use números concretos e progressivos ("dez, cem, mil tarefas") e termos do público ("workers", "skills", "workflow").
- Repita o benefício principal no último terço ("E repito: é tudo grátis!").
- O CTA tem só um destino, dito e escrito igual ("inema.club").

## 2. Fórmulas de gancho (primeiros 1 a 3 s)

| Tipo | Modelo | Exemplo |
|---|---|---|
| Ordem direta | "Para tudo! Você já tá usando o [produto]?" | Vídeo 2 |
| Pergunta de dor | "Você ainda faz [tarefa] uma de cada vez?" | Vídeo 1 |
| Comparação injusta | "Enquanto você faz 1, tem gente fazendo 100." | Vídeo 1 (frase 2) |
| Preço chocante | "Isso custa R$0. Sério." | |
| Segredo | "Ninguém te contou que dá pra [resultado] de graça." | |
| Erro comum | "Se você ainda [faz X], você está perdendo [Y]." | |
| Número | "1.000 tarefas. Zero esforço. Olha isso." | |
| Prova de identidade | "Se você trabalha com [área], salva esse vídeo." | |
| Antes x depois | "Eu levava 8 horas. Agora leva 8 minutos." | |
| Urgência | "Corre, que isso ainda é grátis." | |

O gancho funciona quando **três camadas** chegam juntas no frame 0: imagem (close ou mão na lente), som (scratch + impacto) e texto gigante. Nunca comece com logo ou apresentação.
